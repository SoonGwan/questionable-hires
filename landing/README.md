# Landing page draft

From the repository root, run:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://localhost:4173/landing/ . This Korean draft uses the existing approved character artwork and Montage semantic palette. No build step, third-party JavaScript, analytics or runtime dependencies are required. Motion uses CSS, the Web Animations API and IntersectionObserver, with reduced-motion support.

The skill roster is interactive and the install command can be copied. Evidence links point to the dated decision index and the canonical `benchmarks/featured.json`; no benchmark numbers are maintained independently here. This is a local design preview, not a hosted release.
