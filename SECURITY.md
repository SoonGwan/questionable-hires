# Security and privacy

These skills can guide an agent that has file and command access. They do not grant permissions, install lifecycle hooks, or send telemetry. Commands and model requests still run through your chosen host and account.

Do not paste credentials, private source code, or sensitive execution logs into public issues or pull requests. For a vulnerability, use the repository's **Security → Report a vulnerability** channel when available. If it is unavailable, open an issue requesting a private reporting channel without describing the exploit or including sensitive data.

Reports should identify the affected version, skill or script, a minimal synthetic reproduction, the impact, and any proposed mitigation. Maintainers cannot promise a response SLA during the development preview.

Only the latest development version is maintained at present. Review benchmark logs before sharing them; path replacement alone is not a comprehensive redaction mechanism.
