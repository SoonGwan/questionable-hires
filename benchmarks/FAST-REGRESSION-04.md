exported snapshot and its Git blob, not only the entrypoint hash: all match. All
original fixture files are preserved except the two authorized implementation
cases described above. Successful command traces stay within project scope.

successful later changes are in scope, but rejected targets are not fully
captured; no intent or complete attempted-scope compliance is inferred. Thus
9/9 task criteria is not a claim of comprehensive operational/scope perfection.

as [capture diagnostics](CAPTURE-DIAGNOSTICS.md) explains, absence of those markers
does not prove a complete stream.

protected search, broken search and diagnosis artifacts reproduced the expected
results. Broken search exits 1 with exactly one assertion failure, not a setup
error. History, formatter, mutation and SQL reviews rely on inspected recorded
commands/artifacts, not an additional independent replay in this screen.

but leave the full performance objective open. Helpers demonstrably route and
preserve required evidence; aggregate cost has not improved consistently across
the retained history. No new superiority chart or unchanged-set rerun is warranted.
