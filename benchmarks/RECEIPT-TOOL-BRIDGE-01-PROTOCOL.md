# Receipt direct-tool availability01 — frozen protocol, 2026-09-27

This is a **four-cell, exposed development pilot**, not an all-eight improvement
claim or independent validation. Starting resource `b081240e` supplies identical
Receipt files to both arms. The prior assertion API01 model comparison remains
adverse (+25.03% whole tokens); the v2 codec has no measured model saving.

Mechanism: offer the existing native comparison as a typed local tool, instead
of requiring the model to discover/assemble a CLI call. Candidate may choose the
tool or ignore it. The same skill guidance is installed; no answer hints,
forced tool use, shortened guide or changed quality criterion is introduced.
The bridge's full schema is additional model input, not free context.

Reused single/multiple scheduling-window tasks retain all six current tests,
actual revisions and explicit owned native Python3.11.6. Both tasks authorize
launch-supplied loopback project facilities with a separate host dependency
runtime; native project tests still use standard library only. This equal prompt
clarification reconciles the earlier no-network/no-install fixture constraints
with the supplied local facility. No external services, delegation or changes to
production/tests/resources are authorized. Skills remain matching Receipt only.

GPT-6 Astra medium sessions, one per cell, serial, timeout360 seconds, no retries.
Both arms apps off and exclude web/imagegen/clock namespaces, ignore user config
and rules through the existing collector. Both replace the scoped MCP table;
CLI has no MCP servers, bridge one launch-owned loopback endpoint with only
`receipt_compare` enabled. HTTP helper default native timeout30, host tool

[prototype01](TOOL-BRIDGE-NATIVE-PROTOTYPE-01.md). Ordinary skills have no new
runtime dependency. Source/protocol/resource/runtime identities are frozen by
[runner](run_receipt_tool_bridge_01.py) preparation before execution.

[Host discovery](TOOL-BRIDGE-HOST-DISCOVERY-01.md) and
[host native calls](TOOL-BRIDGE-HOST-NATIVE-01.md) provide actual no-model
connection/native proof. [Cancellation](TOOL-BRIDGE-HTTP-CANCELLATION-01.md)

interrupted RPCs; [forced stdio exit](TOOL-BRIDGE-FORCED-EXIT-01.md) remains
unsafe/declined. A limited normal-cell pilot does not certify host cancellation,
client loss, hard kills or cross-instance concurrency. Limit/uncompleted cell
stops the schedule. Paid output/errors must be retained before review; no repair,
retry, rescore or easier substitute of a failed cell.

Review every original model context and tool result, actual native tests,
assertion arguments/import origins/full commits, unchanged original bytes/modes,
Git index and installed resources, scratch removal and host tool errors. Model
completion/process0 is insufficient. Baseline passing argument inference must
be distinguished from actual observed passing arguments. Unequal optional work
and source-output gaps remain visible. Host/runtime logs and stored contexts
stay private; exports redact private paths and exclude initial system prompts,
authentication/provider configuration and external answer-bearing resources.

Costs: sum original response input+output over the whole model task and reconcile
cumulative usage. Cached input is already input, never added again. Include
schema/connection/failure responses. CLI elapsed is reported alongside **CLI
elapsed + measured bridge startup + settled bridge shutdown**; collector's
post-task export/inventory time is not included and must not be called elapsed
for the entire harness. Bridge lifecycle numbers are never subtracted as noise.
Both raw process time and lifecycle-inclusive comparison must be available.
No cost conclusion before all original evidence is reviewed. Shared host/cache,
correlated reused tasks, n=1 and tool-profile rather than skill-version change

No featured pointer, frozen chart, landing claim or release changes. A favorable
Receipt pilot is only a candidate for broader role/independent validation. The
