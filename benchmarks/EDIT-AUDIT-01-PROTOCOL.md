# Native edit audit01 — frozen before model execution

2026-09-21. Prior Con Artist resources `04bf934`; current `e6aa16e`. One new
author-written original-coordinate text-edit project, with proposal-only and
verified-assertion requests. Not an external repository or independent holdout.
Six Astra medium sessions,360 seconds each,n=1,serial on a shared host/cache.
Proposal order: prior/baseline/current. Verified order: current/baseline/prior.

Hypothesis: current optional `-m unittest` support removes an actual incompatibility
with the requested native invocation and can reduce custom orchestration cost.
It does not guarantee adoption or savings. Entry instructions are unchanged, no
task prompt directs helper adoption, and prior/baseline may use equivalent native
orchestration. Every arm receives identical task files and criteria per request.
The comparison includes all discovery, setup, resource reads, repairs and extra
checks. No helper-use-only exclusions or retroactive effort equalization.

The implementation uses original Unicode character offsets, accepts touching but
not overlapping nonempty ranges, preserves caller lists on success/failure, and
allows empty replacement/empty edit lists. Unsupported types, zero-width insertions,
large-input performance and integrations are excluded explicitly. The task supplies
all paths, forbids source/test edits and persistent artifacts, requires project-local
scratch cleanup and exact native unittest commands. Same-process test-function
binding evidence is explicit for all arms; instrumentation is allowed.

Author preflight runs correct and equivalent code against all supplied tests and
stronger witnesses. Separate forward-application, omitted-overlap and in-place-sort
faults produce real assertions, not setup failures. Existing selected test outcomes
must be `[0,0]`, `[0,1]`, `[0,0]` respectively. Stronger exact-output and list-preservation
witnesses pass correct/equivalent code and fail the appropriate fault; failure-path
preservation distinguishes a changed list from absent ValueError. Fault patches and
author witnesses are not model inputs. Keep every frozen input unchanged once used.

Five proposal criteria and a sixth verified-assertion criterion are embedded in
the model-visible requests/manifest. Review actual same-session tool commands,
native assertions/counts, scope, cleanup, edits and answers. Inspect original
initial messages to establish skill exposure; a later reread is not first exposure.
Original raw records stay private; publish redacted evidence without private
instructions. Author replay cannot fill a missing model execution record.

Freeze fixture/runner/protocol identities, source revision, interpreter version,
resource digests and the complete schedule before launch. An exclusive execution
marker prevents restart. Preserve failures, timeouts, repairs and every scheduled
slot; stop further scheduling on a recognized account limit. Do not run author
tests concurrently with timed model cells. No candidate edits, repeats, exclusions
or replacement attempts to achieve a preferred number.

Report every cell's total input-plus-output tokens (cached input included once),
process wall time, response counts and actual work. Quality/scope and native proof
remain prerequisites, not interchangeable with cost. Any unequal extra work or
captured-output omissions are disclosed. Even a favorable n=1 result cannot prove
general20–30% gains or justify replacing the featured graph. A negative or unused-
helper result remains public and does not justify retuning this exposed project.
