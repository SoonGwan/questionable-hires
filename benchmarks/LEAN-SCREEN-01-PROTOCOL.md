## Execution

Run `python3 -B benchmarks/run_lean_screen.py` once. Exactly 24 fresh persisted
GPT-6 Astra medium sessions: baseline/current/lean once per task, serial,
360 seconds per cell. Baseline installs no target skill; current/lean install the
same role's frozen resources, with only the lean entry body changed. No helper
mandate, automatic repair or retries. Record resource hashes and the complete
schedule before calls. Output refuses an existing directory; stop on account limit.
Runtime diagnostic requires `REQUEST_RETRIES` absent from the launch environment;
runner refuses otherwise rather than changing host settings.

The first six task blocks use every permutation of the three conditions once.
The final two use baseline/current/lean and current/lean/baseline. Each condition
occupies each position two or three times. This balances positions approximately,
not task difficulty or shared host/cache. Record actual initial skill exposure;
disable flags remain requests and catalog presence does not establish availability.
