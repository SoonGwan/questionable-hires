The observer executes explicit callback cases, derives match counts rather than
requiring guessed aggregate failure counts, records primitive actual/expected
failure examples and reports omitted examples explicitly. It preserves tuple/list
identity in reports. All27 supported render combinations execute for current and
each independent code/display/guard substitution; mismatches0/15/0/9 match the
original reviewed authored control. Native required unittest4passes/exit0 runs
separately. Original files and input cases remain unchanged; actual consumer
binding is restored. These are related author controls, not independent validation
or a rescore of prior model attempts.

Six boundary controls detect wrong return, wrong exception type and input mutation,
and reject zero examples, unsupported actual values and invalid expectations.
Case/report bounds are explicit; invalid expectations are rejected before calls.
Completed full observation report is1,733 characters with capped failure examples;
this is a representation size, **not whole-task tokens, time or billing**. Git-free
copy repeats the native controls successfully without history or prior results.

Limits: Python callback execution is unsandboxed, caller-owned and lacks an internal
timeout. The Git-free native control has a30s parent subprocess bound. The first checkout
control completed without an independently imposed parent deadline, a retained
protocol deviation rather than a general bounded-execution claim. The required
unittest subprocess has15s. Primitive encoding limits can reject valid user values.
Exact exception types only; exception-message contracts need separate assertions.
Equality uses Python semantics. If a callback/report raises outside the supported
path, execution aborts; earlier partial observations are not automatically retained.
A complete report is not all checks passing: any mismatch/input mutation remains
visible. Source binding, independence of proposals and contract derivation stay the
caller's responsibility. This prototype is unsuitable as a default helper until
these limits and real consumers justify an interface and model-level measurement.
