A viable consolidation alternative is **one maintained source, vendored as a regular private module inside each skill**. It preserves standalone access and lets the existing installer and resource comparison include the module naturally. Imports must resolve to the bundled copy without searching consumer directories. Command construction, environment choices, provenance interpretation, and public result formatting stay local.

That alternative reduces repeated mechanical fixes but introduces synchronization checks and an internal compatibility boundary. It still distributes three copies. Keeping the implementations local avoids those costs and retains the same behavioral, security, portability, and support boundaries; its explicit cost is reviewing common fixes in three places. The supplied evidence supports paying that smaller cost now.
