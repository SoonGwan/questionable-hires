# Receipt versions01 evidence

[Reviewed interpretation](../../RECEIPT-VERSIONS-01-REVIEW.md) covers all six
scheduled cells, including adverse token/time comparisons.

- `run.json`: completed exclusive schedule, frozen tasks/settings/identities.
- `measurements.json`: original usage reconciliation, elapsed time, exposure and
  tool identity diagnostics. Counters are observations, not causal savings.
- `preservation-review.json`: author source/resource/HEAD/index checks.
- `baseline/`, `predecessor/`, `current/`: two cells each, CLI events, commands,
  answers, final source snapshots, metadata and original artifact hashes.
- Each cell's `original-tool-records.json`: redacted derivative of stored tool
  calls/outputs, with unredacted source/line hashes. Full private rollouts and
  initial context are not published. These are original observations, not replay.

Per-condition `run.json` files are historical preparation snapshots, not final
completion ledgers; the root manifest records all completed cells. Metadata's
capture diagnostics are not task scores. Authored fixtures are development
cases; no independent holdout, superiority or public-release claim is made.
