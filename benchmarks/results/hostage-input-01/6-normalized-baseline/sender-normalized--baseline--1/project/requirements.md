Sender.send must keep one request pending per instance. While pending, a duplicate returns None without invoking its callback or altering the active request. An admitted request returns the exact result or propagates the original delivery error. Both synchronous callback failure and asynchronous failure clear pending; cancellation propagates and clears pending too. Retry is allowed after every settlement; instances are independent. payload is a string. Pass payload.strip().casefold() to deliver. Assert this value with a nontrivial padded/mixed-case input; argument identity is not promised and equivalent fresh normalized strings must be accepted.
Callbacks are cooperative; no network, threads or blocking work.
