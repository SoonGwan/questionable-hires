Sender.send must keep one request pending per instance. While pending, a duplicate returns None without invoking its callback or altering the active request. An admitted request returns the exact result or propagates the original delivery error. Both synchronous callback failure and asynchronous failure clear pending; cancellation propagates and clears pending too. Retry is allowed after every settlement; instances are independent. payload may be any opaque Python object. Pass that exact object to deliver, without copying or coercion. Tests must distinguish a copied/coerced argument from the original, not just equal text.
Callbacks are cooperative; no network, threads or blocking work.
