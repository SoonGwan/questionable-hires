Each frame has an unsigned two-byte big-endian byte length followed by exactly that many payload bytes. Decoder.feed(chunk: bytes) -> list[bytes] accepts any split between calls, including within a header or payload. Return all complete payloads in arrival order exactly once; retain the complete undecoded suffix for the next call. Zero-length frames are valid. Empty feeds must not lose pending data or repeat completed messages. Instances must not share state. Inputs are bytes and payload lengths are at most 65535; malformed-input policy, backpressure, network I/O and thread safety are outside this ticket.
