AccountPanel displays the latest selected account's complete payload. Loading a new account retains the last displayed payload until the newest request succeeds. Starting any request clears a previous displayed error. An older success or failure must never change the newest request's view, error or loading state. The newest success replaces the payload and clears loading; newest failure preserves the previous payload, displays str(exception), and clears loading. A subsequent successful refresh recovers. Transport errors are handled rather than propagated. Only refresh requests and these state transitions are in scope; rendered browser behavior, cancellation semantics and payload validation are not specified here.
