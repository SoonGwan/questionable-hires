# Optional helper tools

[한국어](HELPERS.ko.md) · [Choose a hire](CHOOSE-A-HIRE.md) · [Back to onboarding](../README.md)


Start with a normal skill request; helpers are optional when the project lacks
equivalent support. The Python helpers require **Python 3.9+**; Con Artist's
mutation runner, Receipt and Exorcist also require POSIX. Hostage's standalone
JavaScript module needs a JavaScript runtime, **not Python**; its native tests
use Node.js. Helpers do not install dependencies or run in the background.

| Hire | Optional support / boundary |
| --- | --- |
| Hostage Negotiator | Controlled [Python calls and optional task cleanup](../skills/hostage-negotiator/assets/controlled_call.py) (entry-wait cancellation preserves unconsumed calls; repeated close does not re-cancel async cleanup) or [JavaScript calls and cleanup](../skills/hostage-negotiator/assets/controlled_call.mjs); optional [native evidence retention](../skills/hostage-negotiator/references/native-evidence.md) for unreliable terminal capture. Successful edits and tests may share a tool interaction while retaining separate outcomes. Tests own application assertions; the capture recipe supplies no browser evidence or process deadline. |
| Con Artist | [Disposable Python test audits](../skills/con-artist/references/python-audit.md) with checked selected-file opens, bounded batch-local reuse of normal results across repeated test selections and stronger probes (native probes use their own test arguments even when original selections differ), optional bounded whole-project change detection, and [read-only context collection](../skills/con-artist/references/python-context.md) with optional same-name definition groups and configurable complete-output limits. [Multiline decorator openings](../benchmarks/CONTEXT-DECORATOR-OPENING-01.md) are retained in excerpts and definition ranges without executing source. Optional initial UTF-8 signatures are accepted without changing original hashes or byte limits ([native checks](../benchmarks/CONTEXT-BOM-01.md)). Selected special files are rejected, not silently omitted. Duplicate JSON recipe keys are rejected before native execution, including nested mutation/probe fields. Copy, runner, cleanup and final integrity failures retain returned checks and prior batch evidence as incomplete, while stopping later mutations; missing results and unknown guards (including unavailable scratch-removal lookups) remain unverified. [Automatic context indexing can avoid discarded full-source allocation](../benchmarks/CONTEXT-INDEX-ALLOCATION-01.md) while preserving exact output; this is a native optimization, not a whole-task savings claim. [Import hashing uses bounded chunks](../benchmarks/AUDIT-IMPORT-HASH-01.md); local allocation savings are not measured model savings. Empty suites and missing cached parents of listed qualified imports are incomplete, not successful checks. The optional [native unittest batch recipe](../skills/con-artist/references/native-unittest-batch.md) uses instrumented `python -B -m unittest` with baseline reuse; bootstrap remains the default. Run trusted tests only; not a sandbox or concurrent snapshot. |
| Necromancer | [Named Python excerpts](../skills/necromancer/references/python-regions.md) accept a bounded local file or Git/stdin source without executing it; this is not measured model savings. [Focused Git history](../skills/necromancer/references/focused-history.md), including explicit-base ancestry queries without expanding to other refs. [Complete same-revision hunks can be reused](../benchmarks/SAME-REVISION-HUNKS-01.md); attribution does not settle keep/delete decisions. The [authored ancestry comparison](../benchmarks/ANCESTRY-SCOPE-01.md) preserves scope but does not demonstrate an efficiency gain. [Local patch-selection allocation correction](../benchmarks/HISTORY-BODY-OFFSET-01.md) avoids a full-body copy; it is not a measured model-cost gain. |
| Friday | [SQLite compatibility checks](../skills/friday/references/sqlite-matrix.md), with opened-source identity checks against file replacement. CLI JSON rejects duplicate keys before source reads or SQL. Non-finite result numbers use explicit JSON tags while native API floats remain intact. [JSON output01](../benchmarks/FRIDAY-JSON-OUTPUT-01-REVIEW.md) (2026-09-28, `371b4b1e`→`c9b30fc6`) observes lower tokens/time in two explicitly chosen CLI handoffs; this is not a general or all-eight saving. Not a filesystem sandbox or proof of production rollout safety or other DB engines. |
| Receipt | Isolated before/after checks for [Python](../skills/receipt/references/existing-fix.md) or [native Node tests](../skills/receipt/references/node-comparison.md), with source identity, both results and optional bounded whole-project change detection. Unittest can compare multiple historical versions with one shared current-version run. CLI recipes reject duplicate keys and identify missing/unknown keys before execution. Copy, runner, cleanup and final preservation failures retain returned native evidence with incomplete status and CLI exit 2; unreturned results and unverified cleanup remain unknown. Selected reads reject observed file replacement at open; snapshots are not atomic. Both unittest modes record completion and exit agreement; missing results stop comparison. Optional bounded builtin/pathlib argument observation uses versioned format `v:3` and covers current-thread `assertEqual`/`assertIsNot`; unavailable observations stop comparison and retain native results. Node load records are not dispatch/coverage proof; general model-efficiency improvement remains unproven. |
| Exorcist | [Bounded foreground probes](../skills/exorcist/references/bounded-probe.md). Not for background services. |
| Mother-in-law | [Controlled interaction checks](../skills/mother-in-law/SKILL.md) for compatible UI-less Python components. Its component loader supports dataclass string annotations and runtime type lookup during checks, restoring its temporary module registration afterward. Its native-test transport preserves unconsumed requests when an entry wait is cancelled. Existing project tests take precedence; not browser verification. |
| Landlord | [Review guidance](../skills/landlord/SKILL.md); no separate bundled runtime helper. |
